# 🍁 CampaignFit · 多版位创意适配台

同一套活动创意，一次编辑同时适配**官网横幅、移动开屏、社媒方图**三个版位。
系统用**约束求解**自动给出版式：元素锚定安全区边缘或彼此锚定，带间距、最小字号与最小尺寸约束。
**空间不够时绝不偷偷缩小字号或让元素重叠**——而是明确指出是哪条约束无法满足、差多少像素。

- 技术栈：React 18 + TypeScript + Vite，纯浏览器本地运行（无后端）
- 内置「秋季发布会」本地素材（落日秋山 SVG 背景 + AURORA 品牌 Logo）
- 直接拖动、数值微调、撤销/重做、刷新自动恢复、一键重置
- 单版位人工覆盖与自动继承在界面上明确区分，可逐字段或整版恢复继承

## 运行方式

```bash
npm install        # 安装依赖
npm run dev        # 开发模式，打开终端提示的本地地址（默认 http://localhost:5173）
```

其他命令：

```bash
npm test           # 运行全部测试（Vitest，40 个用例）
npm run test:watch # 测试 watch 模式
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 预览生产构建
```

> 需要 Node 18+。所有数据只存在浏览器 localStorage，断网可用。

## 90 秒演示路径

右侧内置了同样内容的「90 秒演示脚本」面板：

| 时间 | 动作 | 预期现象 |
| --- | --- | --- |
| 0–20s | 主创意标题改为 `秋季发布会 · 新一代极光系列正式登场，预约直播享限定好礼` | 官网横幅正常；**移动开屏立刻标红** |
| 20–45s | 查看移动开屏卡片 | 冲突条点名「标题」与「免责声明」，给出互相侵入的 px 数；字号未被偷偷缩小 |
| 45–60s | 拖动任意画板上的十字准星调整背景焦点 | 三个版位的 cover 裁切同步保住落日 |
| 60–80s | 在移动开屏把标题字号与最小字号都覆盖为 34px | 字段变紫色实线、元素出现「覆」角标，冲突解除，其他版位不变 |
| 80–90s | 点字段 ↺ / 「全部恢复继承」；Ctrl/⌘+Z 撤销；刷新页面；一键重置 | 覆盖恢复、历史回退、草稿仍在、重置回初始素材 |

## 约束模型

- **版位规格**
  - 官网横幅 `1200×400`，安全区内边距 28/72
  - 移动开屏 `360×640`，安全区内边距 40/20
  - 社媒方图 `600×600`，安全区内边距 36
- **纵向锚链**：Logo 贴安全区顶边 → 标题在 Logo 下方（间距 28px）→ 行动按钮在标题下方（间距 26px）；免责声明贴底边。支持 `贴顶 / 贴底 / 在目标上方 / 在目标下方` 四种锚定。
- **横向约束**：左对齐 / 居中 / 右对齐 + 距安全区边缘的边距。
- **硬约束**：字号、最小字号、最大行宽（折行盒）、Logo 高度/最小宽度、按钮高度/最小宽度/内边距。
- **背景焦点**：归一化 `(fx, fy)` 控制 cover 裁切保住的画面中心；窗口在素材边缘处夹回并标记。

求解器按字面约束计算位置（不缩放、不避让），再统一检测：

| 冲突码 | 含义 |
| --- | --- |
| `space` | 纵向锚链放不下（顶链撞贴底元素，或单链溢出安全区） |
| `overlap` | 两元素发生重叠 |
| `safe-overflow` | 元素越过安全区（继续外溢则会被画板真实裁切） |
| `font-floor` | 生效字号低于最小字号 |
| `min-size` | Logo/按钮不满足最小尺寸 |

每条冲突都带涉及的元素与具体像素差值。

## 继承与覆盖优先级

```
内置默认素材（MASTER_ELEMENTS）
   └─ 主创意修改 doc.master        ← 在「主创意」作用域编辑，同步全部版位
        └─ 版位覆盖 placements[*]  ← 白名单字段才可覆盖（字号/间距/锚定等版式字段）
```

- 文案、颜色等**内容字段**只在主创意可改（检查器中锁定显示），杜绝同一句标题各版位不一致。
- 版位可覆盖字段由 `src/data/defaults.ts` 的 `OVERRIDABLE_KEYS` 白名单声明。
- 删除覆盖键（字段旁 ↺、元素级「恢复全部继承」、卡片级「全部恢复继承」）即恢复继承，继承值在检查器中即时可见。
- UI 区分：虚线/普通样式 = 自动继承；**紫色实线 = 人工覆盖**；金色实线 = 主创意相对内置素材的修改。

## 交互

- **拖动**：画板上直接拖元素（横向拖改对齐边距，纵向拖改锚定边距/元素间距）；拖十字准星改背景焦点。一次拖动在历史中合并为一条记录。
- **数值微调**：右侧检查器数字输入（连续编辑合并历史，失焦后分段）。
- **撤销/重做**：工具栏按钮或 `Ctrl/⌘+Z`、`Ctrl/⌘+Shift+Z`（输入框内不拦截，便于改字）。
- **刷新恢复**：文档自动写入 `localStorage`（键 `campaignfit.doc.v1`），脏数据自动回退初始素材。
- **一键重置**：清空全部主创意修改、版位覆盖与历史，回到内置素材（重置动作本身也可撤销）。

## 代码结构

```
src/
├─ types.ts                 # 全部领域类型（规格/覆盖/冲突/版式结果）
├─ data/defaults.ts         # 版位尺寸、安全区、内置素材与默认约束、覆盖白名单
├─ engine/
│  ├─ textMeasure.ts        # 确定性字宽测量与中英文折行（无 DOM 依赖）
│  ├─ crop.ts               # cover 裁切 + 焦点映射/夹回、矩形几何
│  ├─ resolve.ts            # 默认→主创意→版位覆盖 的三层解析与白名单
│  ├─ layout.ts             # 约束求解器：测量、锚链定位、冲突检测
│  └─ index.ts              # computeLayout(doc, scope) 统一纯函数入口
├─ store.ts                 # reducer、撤销/重做（拖动合并）、localStorage
├─ hooks/useCampaign.ts     # 状态 hook、持久化、快捷键
├─ components/
│  ├─ Artboard.tsx          # SVG 画板：真实裁切渲染、焦点/元素拖拽、冲突描边、覆盖角标
│  ├─ PlacementCard.tsx     # 单个版位卡片（拖拽增量→约束字段翻译、冲突列表）
│  ├─ Inspector.tsx         # 检查器：数值微调、覆盖/继承样式与恢复
│  ├─ Toolbar.tsx           # 撤销/重做/重置/安全区开关
│  └─ DemoGuide.tsx         # 90 秒演示脚本
└─ App.tsx                  # 布局：主创意画布 + 三版位 + 检查器
public/assets/              # autumn-bg.svg、logo.svg（本地素材）
```
